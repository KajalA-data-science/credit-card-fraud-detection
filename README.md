# Credit Card Fraud Detection Using Machine Learning

## Project Overview
This project focuses on identifying fraudulent and genuine credit card transactions using Machine Learning classification algorithms.

The objective is to build a classification model that can help detect potentially fraudulent transactions and evaluate model performance, especially when dealing with imbalanced data.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithms
- Logistic Regression
- Random Forest Classifier

*Keep these algorithm names only if both are actually implemented in your notebook.*

## Project Workflow
1. Data Loading – Imported the credit card transaction dataset.
2. Data Cleaning – Checked for missing values and duplicate records.
3. Exploratory Data Analysis (EDA) – Analyzed transaction patterns and class distribution.
4. Data Preprocessing – Prepared features and target variables for model training.
5. Train-Test Split – Divided the dataset into training and testing sets.
6. Model Building – Trained classification models to identify fraudulent transactions.
7. Model Evaluation – Evaluated performance using accuracy, precision, recall, F1-score and confusion matrix.

## Project Objective
To understand how Machine Learning classification techniques can be applied to credit card fraud detection, with particular attention to identifying fraudulent transactions.

## Project File
- `fraud_detection.ipynb` – Jupyter Notebook containing the Python code, analysis and model implementation.

## Conclusion
This project provided practical experience in data preprocessing, exploratory data analysis, classification algorithms and model evaluation for a real-world fraud detection problem.
